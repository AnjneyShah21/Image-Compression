🎨 2. Image Preprocessing (Grayscale Conversion)

Academic Explanation: Standard color images use 24 bits per pixel (8 bits for Red, 8 for Green, 8 for Blue). To build the foundation of Huffman compression, we convert the image to single-channel 8-bit Grayscale using the ITU-R BT.601 Luminance formula: Y = 0.299·R + 0.587·G + 0.114·B. This maps each pixel to an intensity value between 0 (Black) and 255 (White).

🌿 5. Huffman Binary Tree Visualization

Tree Construction Algorithm: The greedy algorithm repeatedly dequeues the 2 lowest-frequency nodes from a Min-Heap, creates a combined parent internal node, and enqueues it back. Left branch represents bit 0 (blue), right branch represents bit 1 (red).

🚧 6. Future Project Stages (PART 2 ROADMAP)

Part 2 Placeholders

The foundation (Part 1) is now complete. The following modules are planned for Part 2 of this college project:

📦 1. Compressed File Packing

Pack the variable-length bitstream into Uint8Array bytes along with the Huffman tree header serialization to generate a downloadable .huff compressed file.

🔓 2. Huffman Decompressor

Parse the serialized Huffman header and reconstruct original grayscale pixel array by bitstream traversal from root to leaf nodes.

🍀 3. Quadtree Decomposition

Recursively divide spatial image quadrants based on variance threshold to eliminate spatial redundancy before/alongside Huffman encoding.

📈 4. Performance & PSNR Comparison

Measure actual compressed file size, execution time (ms), compression ratio, and Peak Signal-to-Noise Ratio (PSNR) across multiple image types.
